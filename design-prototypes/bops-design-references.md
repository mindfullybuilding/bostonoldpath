# BOPS Design References

Last updated: 2026-06-05

This file tracks the websites, product references, and media sources informing the BOPS lightweight homepage prototype.

## Core Sources

| Reference | URL | Current use |
|---|---|---|
| Boston Old Path Sangha | https://bostonoldpath.org/ | Primary source for BOPS identity, welcoming tone, local community context, and current public content. |
| BOPS Weekly Meditation Sittings | https://bostonoldpath.org/practice-with-us/weekly-sittings/ | Source for the prototype Sangha Finder examples, attendance guidance, sitting formats, days, times, and contact expectations. |
| Plum Village | https://plumvillage.org/ | Lineage and resource reference for Thich Nhat Hanh, Plum Village practice, 5 Mindfulness Trainings, 14 Mindfulness Trainings, retreats, songs, and visual tone. |

| Plumline Starting / Building | https://www.plumline.org/starting | Reference for facilitator and builder support, mentoring, directory listing, and community-development resources. |

## Design Notes To Preserve

- Keep BOPS as the local Greater Boston front door, not a duplicate of Plumline or Plum Village.
- Keep Plum Village as the canonical lineage/resource layer.
- Use Plumline and Transformation Hall as sangha-discovery and community-building references.
- Treat SitTogether as interaction inspiration only until governance and privacy questions are answered.
- Keep media usage documented before production; optimize the hero image before launch.
