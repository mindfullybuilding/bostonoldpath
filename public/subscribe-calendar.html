Subscribe to Calendar

Subscribe to stay up to date with days of mindfulness, retreats, engaged practice, and other happenings outside of regular practice sittings. See the instructions below for how to add Mindfulness Communities of Greater Boston to your preferred calendar provider.

Try Apple Subscription Link
Apple Calendar
  1. On iPhone or iPad: open Calendar, tap Calendars → Add Calendar → Add Subscription Calendar. On Mac: open Calendar → File → New Calendar Subscription.
  2. Paste the subscription URL shown above, then confirm the subscription. On Mac, choose your refresh interval and account as offered.
  3. Alternatively, try the Apple subscription link below; if your device does not open it, copy and paste the URL manually.

To remove: On iPhone/iPad, open Calendars, tap the information button next to this calendar, then Unsubscribe. On Mac, select the calendar and choose Edit → Delete.

Apple Calendar official help
Google Calendar
  1. On a computer browser, open Google Calendar. Beside Other calendars, select + → From URL.
  2. Paste the subscription URL above and select Add calendar.
  3. Use the same Google account in the mobile app and enable the added calendar in its calendar list. Adding by URL is done in the web interface.

To remove: In Google Calendar settings, choose this calendar under Settings for other calendars, then Remove calendar → Unsubscribe.

Google Calendar official help
Microsoft Outlook
  1. Open Outlook.com or Microsoft 365 Outlook in a web browser and go to Calendar.
  2. Select Add calendar → Subscribe from web.
  3. Paste the subscription URL, give the calendar a name, and import/save the subscription.

To remove: In the calendar list, open the calendar’s options and choose Remove or Delete. This removes your subscription, not community events.

Microsoft Outlook official help
Yahoo Calendar
  1. Open Yahoo Calendar in a web browser.
  2. Beside Others, use the options menu and choose Follow Other Calendars.
  3. Enter a calendar name and paste the ICS subscription URL above, then continue/save.

To remove: Open the options for this calendar under Others, then select Unfollow.

Yahoo Calendar official help
Proton Calendar
  1. Open Proton Calendar in a web browser. This is a Calendar feature, rather than a Proton Mail subscription.
  2. Beside My calendars, select + → Add calendar from URL (or use Settings → All settings → Calendars).
  3. Paste the subscription URL above and follow the prompts to add the calendar.

To remove: Go to Settings → All settings → Calendars → Other calendars. Open this calendar’s settings, scroll to Remove calendar, and select Unsubscribe.

Proton Calendar official help
Other Calendar Apps
  1. Find an option called Subscribe by URL, Add calendar from URL, or Internet calendar.
  2. Paste the subscription URL above and confirm. Choose a name such as MCGB community events.
  3. Use a subscription to receive later changes. Importing an .ics file once usually creates a static copy.

To remove: Use the app’s calendar settings to remove or unsubscribe from this calendar.
